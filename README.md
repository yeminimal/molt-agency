# Molt Agency Website

A responsive, static agency website for Molt — a multidisciplinary team spanning design, technology, growth, data, security and operations.

## Deploy on Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. No build command is required; the site is static.
4. Add the production domain in Vercel.

## Before launch
- Replace `hello@molt.agency` with the team's real email.
- Replace the CSS-generated case-study artwork with actual project imagery.
- Add individual case-study pages and real testimonials/outcomes where available.
- Add analytics, sitemap.xml, robots.txt and Open Graph assets.
